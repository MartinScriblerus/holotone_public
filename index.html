Public visual runtime for a private instrument

StrangeLoop keeps WebChucK audio private. This site is the copyleft-safe Hydra surface: iframe preview, dual / wall canvas, and notes on playing without writing ChucK by hand.

How-to-play video and update posts will land here.

Approach

  • Play — keyboard / MIDI → Layer A note path in the private app.
  • Network — clock and sessions stay on the instrument origin.
  • Codegen — ChucK VM programs are generated for you; you don’t ship Hydra inside that bundle.
  • Hydra — graph JSON + CV + media URLs cross the iframe via postMessage; pixels render here under AGPL.
